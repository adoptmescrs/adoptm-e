## 🛠️ Troubleshooting Common Issues

❌ **Script Does Not Execute After Injection**
The executor may be outdated or incompatible with the current game version.
**Solution:** Update your executor to the latest build, re-download Azure Latch Script, and try injecting again after the lobby fully loads.

❌ **Adopt Me Script Auto Farm Money Stops Mid-Session**
A server-side update may have shifted task waypoints.
**Solution:** Restart the game, update the Adopt Me Script to the newest version, and enable server hopping to avoid stale instances.

❌ **All Pets Adopt Me Script Shows Incomplete List**
The pet registry may not have loaded completely before the module fired.
**Solution:** Add a five-second delay in `config.lua` by setting `ALL_PETS_DELAY = 5` and re-execute.

❌ **Auto Accept Adopt Me Script Accepts Unwanted Trades**
Trade filters may still be using default values.
**Solution:** Open the overlay settings panel, review each filter rule, and set minimum rarity thresholds before enabling Auto Accept Adopt Me Script.

❌ **Overlay Menu Invisible on Mobile**
Screen resolution scaling can hide the UI on certain Android devices.
**Solution:** Set `UI_SCALE = 1.2` in the config file and restart the Adopt Me Script session.
